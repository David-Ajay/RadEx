# Data Setup Guide

This repository does not include the large dataset files to keep the repo lightweight.

## Required Data Structure

The following directories need to be populated locally:

### 1. Raw Data (`data/raw/`)
- **NIH Chest X-ray Dataset**: Place in `data/raw/nih/`
  - Download from: [NIH Clinical Center](https://nihcc.app.box.com/v/ChestXray-NIHCC)
  - Expected files:
    - `images_001/` through `images_012/` (image folders)
    - `Data_Entry_2017.csv`
    - `BBox_List_2017.csv`

### 2. Processed Data (`data/processed/`)
- Generated by preprocessing scripts
- Contains normalized/resized images
- Run preprocessing after downloading raw data

### 3. Model Checkpoints (`checkpoints/`)
- Pre-trained models and fine-tuned weights
- Download separately or train from scratch
- Expected subdirectories:
  - `phase1/`
  - `pleura/`
  - `pretrained/`
  - `smoke/`
  - `xray_chex/`

## Setup Steps

1. Clone this repository
2. Create virtual environment: `python -m venv .venv`
3. Activate: `source .venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt` (if exists)
5. Download and place raw data as described above
6. Run preprocessing scripts (if applicable)
7. Copy `.env.example` to `.env` and configure

## Data Size
- Raw data: ~50GB
- Processed data: varies
- Checkpoints: varies

## Note
Keep `.env` file private - it may contain API keys and sensitive configuration.
