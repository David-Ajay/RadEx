TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "authentication failed"
Solution: Use Personal Access Token (not password)
         Get from: https://github.com/settings/tokens

Problem: "remote: error: File too large"
Solution: Verify .gitignore is working:
         git ls-files | grep "\.pt$"
         (should return nothing)

Problem: "fatal: repository not found"
Solution: Create repository first at https://github.com/new

Problem: Push is slow
Solution: Normal - 600MB upload takes time
         10 Mbps: ~8 minutes
         50 Mbps: ~2 minutes
